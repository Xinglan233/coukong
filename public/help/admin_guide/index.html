管理员指南

当前按钮路径已上线；版本与待验项见 发布检查表。

管理员根凭据只在 Worker Secret 保存，不放前端、示例或聊天。先按 部署说明 创建免费 D1、迁移、配置精确 CORS，再由账号持有人安全生成至少 256 bit 的随机根凭据与独立创建码。Secret 输入在本机终端交互完成，不复制到公开日志。

从首页“管理员入口”进入 /admin，填写“管理员密码”，点“进入管理”，换取 1 小时管理会话；会话尽量驻留内存/sessionStorage，“退出登录”撤销。隐藏路由不是鉴权。根凭据轮换通过重新设置 ADMIN_ROOT_SECRET；已有短期会话在过期前仍有效，紧急事件须撤销 admin_sessions 中相关记录并验证旧会话失败，不承诺更换根凭据会自动撤销所有已签发会话。

CREATION_MODE 固定 invite，未配置 CREATION_CODE 时创建失败。创建码单独交给队长，队员只需小队邀请。禁止未实测防滥用时开放无限匿名创建；当前没有开放创建模式。

本轮公开活动与地图

活动与地图后台正在实施，真实按钮稳定后补操作步骤，不把下面要求写作当前已上线能力。管理员选择通用或漫展类型，填写基础资料和来源；通用活动不强迫有地图。漫展可没有地图发布，但必须显示资料未提供。网页表单与 JSON 两条路径都需真实可用。

地图上传需已获授权来源和持久媒体资源。上传校验后再绑定活动，随后标地点、核实入口与通道，再预览发布；未经确认的线不能参与导航。改图或通道版本要保留旧引用，路线提示复核，不能让已确认日程无故重填。当前 Blob 待核验/必要审批，R2 不启用。详情见 地图指南、路线限制 与 部署决策。

公共模板

选择“新建模板”或已有模板，打开“导入活动文件”，上传或粘贴活动包，点“预览”。核对来源、日期与场次后，点“保存并发布”供队长使用，已发布模板点“保存并下架”；新建或未发布模板点“保存为未发布”。每次保存都生成新版本，并立即切换该模板的最新公开状态，没有另行发布草稿的步骤。历史版本保留，但旧已发布版本不会在最新版本下架后重新出现。已有小队安排不变。发布决定该版本进入公共列表；下架不会删除现有小队快照。更新必须带 expectedRevision 并生成新版本，不能就地改变所有队的安排。维护者用 JSON 格式，不得在活动包写成员/管理权限。

REDLAND 模板是 2026-10-02 至 10-06 空场次框架，09:00–21:00 待确认；真实资料要确认后再发布，不能宣传例子为官方资料。后台仅应展示必要小队元数据用于停用，不展示全员私密备注。滥用处理可关闭/归档小队，保留脱敏必要记录，避免输出凭据。

日常查配额、备份、故障与回滚见 运维。发布前核验根凭据和创建码未进入 dist、Git 和日志，退出后会话失效。当前真实后台界面/远程操作是否通过以 发布检查 为准。
