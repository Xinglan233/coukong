管理员指南

打开 /admin，填写“管理员密码”，点“进入管理”。会话有效1小时，“退出登录”会撤销当前会话。密码由持有人安全提供，不发群聊或公开记录。首次配置与轮换见 部署指南。

创建与发布活动

1. 点“新建活动”，选择“通用活动”或“漫展”，填写名称、日期、时区、每日开放时间、地点和来源。

2. 用“添加场次”“添加地点”录入，或在“导入或导出活动文件”上传、粘贴 JSON，点“校验并使用”。此时只是编辑草稿。

3. 点“保存草稿”或“发布”，核对差异，再点“确认保存”。保存草稿不会替换当前已公开版本。

4. 顶部“编辑／预览”只切换呈现，不保存。取消、归档同样先预览差异，再确认。

通用活动无需地图。发布表示资料进入公开列表，不表示来源已获官方确认。活动文件不得包含成员身份或权限，格式见 JSON 说明。

上传地图和校对地点

新活动先保存，再进入地图编辑。填写名称与来源，上传有权使用的 PNG、JPEG 或 WebP。可信处理完成后绑定资产，返回活动预览并确认保存。上传失败不会替换旧图。

在地图编辑器选择标点、移动、连线等模式，核对名称、编号和坐标。通道需人工确认方向、启闭和可走性；地点明确连接路网节点后才能计算路线。换图必须升版并重新校对，旧资产与历史引用保留。

没有坐标可保留“未定位”，没有通道不填猜测路线。地图规则见 地图指南，时间估计见 路线说明。

发放建队码

打开已发布活动的“建队码”，点“生成建队码”，成功后“复制长文字码”交给队长。默认有效24小时、绑定当前活动、单次使用。完整码只在生成时显示；历史列表不提供明文找回。

可用码可确认撤销，已建立的小队不会因此删除。管理员密码、建队码、队长恢复入口和成员邀请不能互相代替。

图片空间与失败上传

在“图片空间与失败上传”查看预算。清理时点“清理失败上传”并确认，仅清理到期15分钟后、未被当前或历史资料引用的未完成或失败资产。已就绪图保留，失败中断时预算仍保留。备份与恢复见 媒体备份 和 运维。

旧模板兼容

旧公共模板入口支持“新建模板”“保存并发布”“保存并下架”“保存为未发布”。每次保存生成新版本并切换最新公开状态；最新版本下架后，旧已发布版本不会复活。已有小队快照不变。它与活动编辑的“保存草稿”流程不同。
