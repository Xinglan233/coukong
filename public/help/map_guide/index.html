地图与标点

本轮活动地图功能实施中，尚未完成生产验收。以下说明资料约定与准备要求；实际上传、标注按钮在功能稳定后对齐。不能据此认定 REDLAND 已可导航。

先准备有权使用的图

地图必须有来源和使用授权记录，管理员发布不等于来源已核实。当前 A02 来源图只有局部且没有重新分发授权，不作为完整正式底图。REDLAND 开放时间、真实地图、入口、关键摊位与可走通道仍需确认；第三方候选场次表有 998 项、缺 2 项且非完整官方资料。

上传只接受实际 PNG、JPEG、WebP，不接受 SVG、HTML、脚本、PDF 或动图。首发采用有界字节、尺寸和像素限制；最终数值以共享合同及已执行运行时测试为准，未经测试不宣称 12MiB/2400万像素均可用。图片去除非必要 EXIF；图中文字应仍可读，不能无声过度压缩。

地图文件单独存持久媒体，活动 JSON 只绑定 assetKey、哈希、尺寸和版本。浏览器 Blob URL、函数临时磁盘、大图 base64 和 D1 JSON 都不能代替真实媒体存储。当前 Vercel Blob 尚待资源核验/必要审批；没有开通 R2，不以免费额度名义开启可能自动计费资源。

坐标与校对

原点是实际图片左上角，x 向右、y 向下，坐标在 0–1 之间，关联地图 ID 与版本。2000×1000 图片的 (0.25,0.6) 对应像素 (500,600)。容器留白不计入坐标，标点、通道、路线共用同一缩放平移变换。

标点应关联稳定地点 ID，不以名称或摊位编号认领。未知位置保持未知，不补 (0,0)。先标入口和实际需要的位置，再核对列表里尚未定位的地点；缩放时不能误标点。地图与列表是同一份地点资料，地图加载失败时列表与日程仍可用。

裁剪、旋转、改布局或换底图后，点位和路线需要重新校对。仅构图完全不变的等比例重采样才可经预览确认复用。保留旧地图版本与引用直到迁移/回滚完成，不覆盖同一路径假定缓存已更新。深色模式不反色处理底图图例。

离线与备份

只有已成功下载的活动地图和匹配版本数据才能离线看；首次打开不能称完全离线。准备时确认地图、地点、通道、个人计划的版本与最后更新时间，失败保留可识别的旧快照并提示过期。个人快照与公开地图缓存分开。

数据库备份不包含图片原文件。恢复必须同时验证媒体、哈希、版本与引用，并在隔离环境真正打开地图；缺资产显示缺失，不能把恢复 SQL 成功当作地图恢复通过。详见 部署决策 和 路线限制。
