文档中心

用户手册

- 新手上路：选择活动、填写计划、同行、恢复与离线。

- 队长指南：建队、邀请、查看进度、更新资料。

- 地图与地点：看图、标点、换图与离线地图。

- 路线与时间：站点顺序、通道、停留和时间估计。

管理员

- 管理员指南：活动编辑、发布、地图和建队码。

- 活动 JSON 格式：字段、限制、示例、导入与导出。

开发文档

- 架构：前端、Worker、D1、本机与媒体职责。

- API：权限、请求响应、版本与幂等。

- 日期时间：分钟精度、时区、缓冲和共同空闲。

- 设计规则：已采用的组件与界面规则。

- 测试：本地命令与验证范围。

- 功能状态、维护计划。

部署与维护

- 部署指南、部署决策。

- 运维、备份与回滚、媒体备份与隔离恢复。

- 发布检查与证据、变更记录。

隐私与安全

- 隐私说明、安全说明。
