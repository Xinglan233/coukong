文档中心

新用户与队长

- 新手上路：收到邀请、分钟填写、确认、恢复与离线。

- 发起人指南：创建、邀请、JSON 与资料变更。

- 活动 JSON 格式：字段、示例、错误与限制。

- 地图与标点：来源、坐标、换图和离线地图。

- 路线与时间：清单、可信路网、单位与估计限制。

- 隐私说明：数据可见范围及删除。

管理员

- 管理员指南：初始化、创建保护、模板与凭据。

开发

- 架构、API、日期时间。

- 测试、实施计划、变更记录、安全说明。

部署与维护

- 媒体备份与隔离恢复：数据库、历史引用、净化源图与显示图共同校验。

- 部署决策、部署指南、运维与恢复、发布检查表。

规范描述接口约束；勾选的发布检查才表示实际验证。历史基线与当前通用版不得混用。
