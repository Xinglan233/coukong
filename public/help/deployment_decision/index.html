部署决策

当前选择

沿用已经上线的 Vite/React 前端、Vercel、Cloudflare Worker API 与 D1。多人业务有实际云端持久化，不是单机演示；增加活动、地图与路线不构成重写服务器的理由。首发保留无需购买或维护自有服务器的完整在线方案。

当前生产多人功能 Worker 标识仍为 9090be47ed732b5afd5323d20515be1fbb4cb84f。后续纯文档前端 PR #4 合并提交 b29c14a 不代表本轮活动地图后端已上线。本轮活动优先、个人计划与地图扩展在功能分支实施，实际上线须另记测试、媒体恢复和真实版本。

媒体存储待验

数据库放资产 ID、哈希、尺寸、版本与引用，对象存储放图片。Vercel Blob 尚待账号计划、免费额度、私有访问、上传方式和超额行为核验/必要审批，当前不声称地图上传已生产可用。R2 未启用，不能因其有免费额度未经同意开通计费订阅。没有可持久存储时，不把临时 URL、构建内示例图或函数磁盘伪装成后台上传成功。

公开图与草稿/私有图必须分别处理权限；长期管理密钥不能进入资产 URL。上传、校验、引用发布分阶段，失败不损坏旧版本；数据与媒体不是同一个数据库事务。导出恢复要覆盖两者与版本引用，不把私人资产提交公共仓库。

成本、网络与可迁移性

保持免费计划，不自动购买、升级、购买域名。Worker/D1 与 Vercel Hobby 个人非商业用途限制见 运维说明。托管额度与实际中国大陆网络需要实测；远程可访问不是现场可用证明，最大图像/JSON/路网规模也需验证 CPU、内存和流量。

媒体与数据库操作集中在薄适配层，稳定 ID、权限验证、DTO、分钟算法和导出格式继续共用。每次部署只有一个有效后端，不做双写或自动跨云切换。换域名时提示本机凭据/缓存不会自动跨域，先保存恢复入口与导出。

自托管适配是未实现的 P1。尚无可验收的 Node/SQLite/持久卷或 Docker Compose 自托管版本，不要求用户为本轮先买服务器；软件开源/免费不意味着服务器、域名和带宽免费。未来只有实际网络、托管限制或运行需求阻断时再评估，不能长期分叉两套协议。GPS 配准与自动定位同为未实现 P1。

部署步骤见 部署指南，现场资料与回滚仍需按 发布检查 分别记录。
