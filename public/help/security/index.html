安全说明

不要提交 .dev.vars、管理员根凭据、创建码、访问 token、恢复链接或 D1 私人导出。前端 VITE_* 全部公开，只放 API 地址等公开配置。根管理员凭据使用 Worker Secret，短期会话退出时撤销；邀请、管理、成员权限分开，删除/移除撤销对应权限。

所有写入必须由 API 检查身份、资源归属、大小、结构和业务约束；参数化 SQL，版本 CAS，精确 CORS 和 CSP。不要在日志中记录 Authorization、fragment、请求私人正文或 SQL 异常。输入文本按纯文本渲染。活动包不得携带权限。

发现问题应通过已知维护者的私人联系渠道报告，不在公共 issue 发布凭据或可利用的私人数据。当前没有经核实的专用漏洞邮箱，不提供虚构报告地址。Cloudflare/Vercel 账号授权及持久权限扩大须由账号持有人审批，禁止自动付费。

发布验证和未验证边界见 发布检查表，数据访问说明见 隐私。
