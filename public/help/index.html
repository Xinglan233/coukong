新手上路

我收到邀请，第一次填写

1. 在浏览器打开发起人提供的小队邀请。确认标题、日期、活动时区和资料来源提示。

2. 填自己的名字加入。同名不会覆盖别人，每人有独立身份。名字不是恢复凭据。

3. 在“安排”选择日期，添加“可参与时间”。直接输入开始 13:07、结束 13:52；手动输入精确到一分钟。选择步长默认 15 分钟，可切 5/10/30 分钟，不会改已有区间。

4. 有预约就勾选公共场次或添加忙碌安排，填写自己的缓冲分钟。标题、地点、备注默认只供本人读取。选择场次不等于官方预约。

5. 检查后点击“确认提交”。看到服务端已提交状态才算完成；“已保存到本机”只是草稿，别人尚看不到新内容。

6. 打开“共同空闲”查看全队结果和等待成员。选中的人有未确认或需复核回复时，不会显示假的全员有空。需要比较部分人时，明确选择成员子集。

7. 在“成员”点击“保存我的恢复链接”，单独收藏或保存在自己的密码管理器；不要发群里。修改时间后再次确认提交。

不能参加也可以明确提交空的可参与区间；刚加入还没填写与“已确认不能来”不同。

我发起一次凑空并上传活动 JSON

1. 首页选择“发起一次游”，填写创建码、标题、日期与每天候选范围。约饭不需要展位、IP 或场次。

2. 创建后把“邀请大家”链接发给成员，单独保存“管理入口”。管理入口不能作为邀请发群。

3. 在管理入口打开活动 JSON 导入，上传文件或粘贴文本。可先下载 最小模板 或 完整示例。

4. 阅读预览中的日期、每天开放区间、场次数量、来源警告和新增/修改/移除差异。修正字段错误后再预览。

5. 明确确认导入，等待提交成功与回读。错误包整包拒绝。更改时间结构后提醒大家复核；单纯改标题说明不会让大家无意义地重填。

6. 自己要填时间也需加入独立成员身份。管理权限不能代替成员确认。

详细格式见 JSON 说明。REDLAND 五天模板暂无官方场次，09:00–21:00 未确认，必须核实后才用于真实协调。

找回、离线与常见问题

换设备用个人恢复链接；只凭名字不能找回。邀请链接是加入新成员的入口，不是原身份恢复。清除网站数据会丢本机凭据和未提交草稿，因此先保存恢复链接和个人导出。

断网编辑会保留本机草稿，联网后主动重试提交。遇到版本冲突先刷新比较，检查新活动资料，再重新确认，不要以为旧草稿已经覆盖云端。页面显示最后成功获取时间；离线快照可能过期。

手机浏览器可用“添加到主屏幕”。首次未访问前不能离线使用；更新提示出现时先保存草稿。OCR 语言资源失败时改用手动输入，识别原图默认不上云，识别结果必须本人校对。

“为什么不是全员结果？”查看选中成员是否都已确认，资料是否刚变更，以及是否有人确认不能参加。不要把“只看已确认成员”的子集结果当成全员结论。

旧版资料

首页“旧版数据”可导入旧版备份，仅在本机保留原文。选择本人资料来源后，在小队安排选择“导入本人旧 REDLAND 2026 安排草稿”，明确确认年份，再检查并提交。旧朋友只是静态快照，不替他们加入或确认。迁移失败也保留原始内容可下载；活动包不能在旧备份入口导入。旧版 OCR 在 /legacy 作为辅助能力保留。
