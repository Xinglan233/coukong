新手上路

直接小队填写流程已上线；活动、地图与个人计划的新界面仍在隔离预发布验收。版本与待验项见 发布检查表。

我一个人逛（本轮新界面，尚未云上线）

1. 首页按名称、类型或日期状态选活动；资料更新时间按活动时区显示。漫展进入“逛展”，通用活动进入“活动”；查看来源、日期和地点。

2. 从地点列表或地图打开详情，点收藏。进入“计划”→“收藏”看清单，可标记去过或加入路线；这些操作不占日程时间。

3. “计划”→“日程”选日期，点“本日在场时间”设置在场时段；点“新增日程安排”，可搜索本活动的摊位、地点和当天已公布场次。场次会带入准确时间和已知地点；地点没有公布时间时由你填写。也可点“添加自定义安排”，例如13:07–13:52，点“保存安排”，再点“保存个人计划”。场次加入计划不代表官方预约。

4. “计划”→“路线”选起点，调整站点顺序。只有已确认通道才显示可走路段；无资料保留清单，不拿直线作导航。

5. “我的”→“恢复与导出”保存个人入口。现场前点“为现场准备离线数据”，看成功状态、版本与更新时间；没有下载成功不能称已离线准备。

“我的”→“时间设置”可设置本人0–120分钟缓冲和5/10/15/30分钟快捷步长。缓冲修改后仍要保存个人计划才上传；快捷步长是当前设备的活动偏好，仅影响之后添加的区间，不改已有13:07–13:52。

“恢复与导出”→“导入个人计划”可选文件或粘贴本人备份，预览后点“替换本机草稿”；检查安排，再点“保存个人计划”才更新云端。导入要求活动一致，新备份还要求本人身份与时间/地图版本一致；恢复链接另行保管，数据备份不会授予任何权限。旧无身份字段的个人计划备份仅在已打开本人入口且活动匹配时可预览。

“恢复与导出”→“删除云端个人记录”需要确认，删除本活动的个人计划、收藏和路线并使原恢复链接失效；小队中已提交的回复保留。“移除此设备资料”只清理当前活动的本机入口、草稿、待提交记录和离线地图，云端数据保留，其他活动及小队入口不变；先保存恢复链接和计划备份。

个人计划过大时，请减少备注或记录再保存；空间已满或网络失败时保留本机草稿，不能把失败当作保存成功。很久之后重试或另一设备已修改时，先回读云端计划并核对，再保存。恢复入口不是私人计划历史档案，重要安排请另行导出备份。

地图更换后，旧点位与通道要重新校对；待核对的地图不用于可走路线。即使只是等比例调整图片，也要先保存替换，再核对位置，不能直接沿用为已确认导航。

我们几个人同行（本轮新界面，尚未云上线）

1. 在同一活动打开“同行”，创建小队或打开邀请对应的小队。

2. 点“同步本人计划到此小队”，明确核对资料版本，再在小队“日程”提交。个人保存与小队提交是两步；收藏和路线不会分享给小队。

3. 在“凑空”看选中队员的已确认结果；未提交或需复核者不会被偷偷忽略。队长在“成员”→“管理小队”邀请大家，公共来源活动只通过“核对并更新活动资料”复核，不用私人JSON覆盖公共资料。

新活动个人/地图功能已落在分支代码，隔离云PNG上传、公开读取与新路径恢复已验证；最新受保护前端完整云链路和现场网络仍待验，下面是现有已上线的直接小队填写流程。地图与离线细节见 地图指南，路线估计边界见 路线说明。

我收到邀请，第一次填写

1. 打开队长发来的邀请，确认活动日期与时区，填写“怎么称呼”后加入小队。

2. 底部选“日程”，切换日期，点“本日在场时间”，选择“在场”，开始填 13:07，结束填 13:52，点“保存”，再提交给小队。

3. 有安排时点“手动添加”，从场次库选择，或用“自定义”填写，再点“保存”。场次选择只记录计划，不代表官方预约。

4. 检查日程，点“提交”。看到“已提交”才算完成；本机草稿别人还看不到。截图识别也要先校对、保存，再提交，原图只在本机识别。

5. 底部选“凑空”看结果。默认比较全队；有人未提交或需要重新确认时，会显示等待。要比较部分人，请明确选择队员。

6. “日程设置”可以改称呼、缓冲和选择步长。默认 15 分钟，可切 5/10/30 分钟；已有 13:07–13:52 不会取整。

7. 底部选“成员”→“我的入口与备份”→“保存我的恢复链接”，私下保管。需要备份时点“导出个人安排”。修改后记得再次提交。

不能参加也可以明确提交空的可参与区间；刚加入还没填写与“已确认不能来”不同。

我发起一次凑空并上传活动 JSON

1. 首页点“创建小队”，填标题、日期、每日开放范围和管理员提供的创建码。

2. 创建后在底部“成员”→“管理小队”复制邀请发给队员，单独保存管理恢复链接；不要把管理入口发群。

3. 在“管理小队”打开“导入活动文件”，上传 JSON 或粘贴文本，点“预览”。可先下载 最小模板 或 完整示例。

4. 核对日期、开放范围、场次和来源警告，点“确认导入”，等待成功。错误包不会部分写入；活动时间改变后请队员重新确认。

5. 队长自己也要以队员身份填写；管理权限不能替别人提交。

详细格式见 JSON 说明。REDLAND 五天模板暂无官方场次，09:00–21:00 未确认，必须核实后才用于真实协调。

找回、离线与常见问题

换设备用个人恢复链接；只凭名字不能找回。邀请链接是加入新成员的入口，不是原身份恢复。清除网站数据会丢本机凭据和未提交草稿，因此先保存恢复链接和个人导出。

断网编辑会保留本机草稿，联网后主动重试提交。遇到版本冲突先刷新比较，检查新活动资料，再重新确认，不要以为旧草稿已经覆盖云端。页面显示最后成功获取时间；离线快照可能过期。

手机浏览器可用“添加到主屏幕”。首次未访问前不能离线使用；更新提示出现时先保存草稿。OCR 语言资源失败时改用手动输入，识别原图默认不上云，识别结果必须本人校对。

“为什么不是全员结果？”查看选中成员是否都已确认，资料是否刚变更，以及是否有人确认不能参加。不要把“只看已确认成员”的子集结果当成全员结论。

旧版资料

检测到旧数据时，首页有“查看旧版数据”链接。需要导入旧备份时打开 /?legacy=1，原文仅保留在本机；选择本人资料来源后，在“成员”→“我的入口与备份”点“导入本人旧安排”，明确确认 REDLAND 2026 年份，再检查并提交。旧朋友只是静态快照，不替他们加入或确认。失败也保留原文可下载，活动包不能当作旧备份。旧版安排与 OCR 仍在 /legacy。

看地图、找地点

漫展的逛展页可切换“地图”和“列表”，桌面同时显示两者。搜索名称、展位或标签；点“仅收藏”可只看本人收藏。没收藏时显示“暂无收藏”，不会把它变成日程安排。

地点详情里的“分享地点”复制公开地点链接，不含个人恢复权限，也不会替朋友收藏或加入安排。不能自动复制时，可复制出现的“地点链接”。

首页“最近活动”只记录此设备打开过的活动，和“最近小队”分开。它不会自动跳走；移除此设备的活动资料后，对应最近活动记录也会清除。

选择离线地图

“我的”→“为现场准备离线数据”，选择本活动要下载的地图，再点“准备所选资料”。活动资料、地点和通道列表始终保留；个人草稿单独保存在本人设备。可以不选地图，只准备列表。

下载前显示资料版本、时间版本、地图版本和资料更新时间。地图大小按实际显示文件元数据估计；无法核实时会显示“大小暂时未知”，不会假报零。成功后显示准备时间和已下载地图数，未下载的地图仍需联网。

下载失败或期间资料更新会保留上次完整快照。离线编辑尚未上传；恢复联网后仍需保存个人计划，遇到版本变化先核对再保存。

发起日常活动（开发分支，尚未上线）

首页点“发起日常活动”，填名称、日期和候选时间，再填写站点创建码。创建后先进入自己的通用活动，尚未建立小队也可以排个人计划。活动不在公开列表中。需要朋友同行时到“同行”创建小队；朋友打开邀请后直接进入对应活动和小队。

创建者在“我的”点“编辑活动资料”，修改标题、日期或每日开放时间；先“预览修改”，再“确认保存活动资料”。未确认的编辑只保存在本机，刷新后可重新打开。更新不会自动覆盖已有小队的活动快照。

“我的”→“恢复与导出”分别保存个人恢复链接和日常活动管理链接。管理链接可打开资料管理入口；个人链接只能改本人计划，不能当作邀请群发。已提交小队回复不会因个人计划变化自动更新，仍须本人明确逐队同步、提交。

活动资料可见且在线时每60秒最多自动读取一次，隐藏页面停止；失败按1、2、4、8、15分钟退避。活动取消或资料变更后会提示，本机未保存计划保留；没有联网时不能保证及时收到变更。

在场时间的“保存”只保存本机草稿。选“不能参加”是明确回复；没有填写的日期仍显示“尚未确认”。快捷步长默认15分钟，可切5/10/15/30；切换不会改变13:07–13:52，只有加减按钮会按步长调整时间。个人云端保存与小队确认是两件事，小队须本人主动提交。
