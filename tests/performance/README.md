# 有界规模测量

这不是线上负载测试或 Cloudflare 免费 CPU 配额通过证明。数据全部为明确标识的虚构夹具，没有真实人员资料、权限凭据或生产写入。

## 运行

在仓库根目录运行（现有 Node 与锁定依赖）：

```sh
node --import tsx scripts/measure-activity-scale.ts --output /tmp/activity-scale.json
node --import tsx scripts/measure-activity-scale.ts --worker --output /tmp/activity-scale-worker.json
```

`--worker` 使用独立、临时的 Miniflare/workerd 和真实本地 D1 数据库，执行现有迁移。它不连接 Cloudflare 账号、不复用开发数据库、不占用开发端口8787、不上传媒体。需要本机回环端口权限；默认沙箱拒绝时不能写成测试失败或云端不可用。数据库在运行结束时由 Miniflare 正常释放。没有设置自动性能阈值，也不根据一次耗时强行判 CI 失败。

## 实测范围与结果

证据文件：[activity-scale-20261001.json](activity-scale-20261001.json)。2026-10-01 00:42 UTC，本机 darwin/arm64，Node v26.4.0。完整工作树 Worker 构建摘要保存在证据中；此记录不是生产对应提交的证明。

数据保持全部计数：5天、1000地点、1000活动/1000场次、2000节点、4000边、50成员，每人500条安排，共25000条；100个路线站点按固定顺序计算99段。使用一张仓库虚构示例地图，地图文件没有进入业务 JSON。数据包820320字节，未截断。

脚本真实断言：严格解析、生成的 Schema 与业务校验通过；固定站点顺序没有改变，每段端点匹配且可达；50人确认后的共同空闲497段；`13:07–13:52`回读原样；原精确共同空闲三段及15分钟筛选仍正确。1001地点、2001节点、4001边被拒绝。1000地点各增加1000个ASCII描述字符后，1837320字节超过独立1MiB上限，被明确拒绝，未静默截断。字段和计数分别合法并不意味着可以超过总字节上限。

Node测量分开记录严格解析、Schema/语义、完整解析校验、固定顺序Dijkstra、50人投影与共同交集。分别取10次（路线3次）的墙钟和`process.cpuUsage()`，包含冷态与暖态；证据保留每次样本。Node进程CPU包括垃圾回收及进程内线程活动，不能等同于线上请求CPU；RSS是累计进程观察值，不能当作每次请求的独立峰值。此次累计观察超过128MiB，不据此声称Worker内存配额通过或确定失败。

真实本地Worker/D1完成105个API请求，全部200：管理员草稿保存、建队、50次独立加入、50次本人提交、共同结果和小队回读。加入请求墙钟中位数8.55ms，个人提交中位数16.79ms；管理员最大包草稿写入110.73ms，共同结果读取60.24ms。以上是本地墙钟，不是CloudflareCPU。测试没有模拟媒体已公开或假造可用资产。

## 明确未通过的门禁

- Cloudflare Workers Free每请求10ms CPU、128MB内存和云端D1查询行数/额度：本地工具没有对应可信请求级指标，仍需隔离线上实测。Node完整解析校验的CPU已明显超过10ms，必须保留该风险，不能用本地200宣称可在免费上限运行。
- 最大规模下浏览器1000标点、密集标签和低性能手机操作没有实测。本次只测图算法，不能替代前端地图性能。
- 五张12MiB/24MP图像处理、衍生图与临时资产占用尚未在该脚本验证。
- 最坏本地共同结果响应1303822字节；50×大量细碎区间会放大下载量。测试成功不等于此负载适合现场弱网；不能将最大计数宣传为现场性能保证。

后续优化必须保持分钟精度、身份范围、确认状态和真实区间。不允许为了性能静默删数据或按网格取整。
