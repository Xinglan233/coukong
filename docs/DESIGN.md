## 2026-10-01 前端结构与样式重构

按用户三张原版截图把在线端统一成一套视觉，业务算法、权限、CAS、JSON、URL 与部署未动；E2E 契约（按钮文案、aria、.sched-row/.overview/.activity-list-group 等类名、role=status/alert）保留。verify 全套通过；41 项浏览器测试 40 过 1 败，失败项为交接文档已记录的管理员登录真实限流，与本次改动无关。

采用规则：

- 统一页头：活动内四页共用「返回 + 当前页标题 + 一行活动上下文」结构（activity-page-header）；原三个页重复的「活动时间」折叠条移除，日期区间并入页头副标题。逛展页保留完整说明与资料来源折叠条。
- 日期展示统一走 src/online/activity/fmt.ts：区间 mdRange/rangeText（10/03–04，跨年带年份）、dateCn（10月3日 周六）、stamp（10/1 09:47）。存储、协议、算法仍用原始 ISO 值；凑空更新时间、我的资料获取时间、场次分组头均已转换。活动列表行的「资料更新：」保持原格式（E2E 断言）。
- 场次列表按天分组（sched-day / sched-day-head），行内不再重复原始日期。
- 活动列表行分层：标题 / 日期·类型·状态 / 地点 / 资料更新小字（event-updated）。筛选仍是两个原 select（E2E 依赖 aria-label 与 option 值），仅压缩高度。

- 桌面 ≥900px 逛展保留地图与地点列表双栏；移动端单栏切换不变。
