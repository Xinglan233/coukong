# 管理员指南

公共模板管理已上线；本轮活动与地图管理仍在隔离预发布验收。版本与待验项见 [发布检查表](RELEASE_CHECKLIST.md)。

打开独立管理员地址 `/admin`，填写已有的“管理员密码”，点“进入管理”。普通用户页面不放管理员或帮助入口。登录成功后管理会话有效1小时；“退出登录”会撤销当前会话。密码只由持有人通过安全渠道提供，不发群聊或公开记录。

公开活动由管理员在活动编辑页生成活动专属建队码，交给队长；队员只需小队邀请，不需要建队码。原手动/私人小队入口的站点创建码保持兼容。首次后端配置、根凭据与轮换由部署维护者按 [部署说明](DEPLOYMENT.md) 和 [安全说明](../SECURITY.md) 操作，不是日常管理员发码步骤。当前没有无限匿名开放创建。

## 创建活动与维护地图（本轮新界面，尚未云上线）

1. 进入活动管理，点“新建活动”，选择“通用活动”或“漫展”，填写名称、日期、时区、每日开放时间、地点和资料来源。通用活动不用填地图。
2. 用“添加场次”“添加地点”录入，或在“导入或导出活动文件”上传JSON。点“预览保存”，核对后确认保存；修改先是本机草稿。新活动先保存，再上传地图。
3. 漫展地图编辑填写地图名称与来源，上传有权使用图片。上传净化完成后再把资产绑定活动，标点、通道仍先进入本机草稿；返回预览并确认保存后才更新公开资料。隔离预发布已实际验证图片上传、净化、绑定和读取，完整媒体恢复及新版本云端个人流程仍待验，尚未生产发布。
4. 核对地点位置及其“通道连接点”，人工建立真实通道，标明方向、可用与确认状态。缺通道不假称导航，换图需要重新校对。顶部“编辑／预览”只切换当前资料的可编辑与只读呈现，不自动保存或发布。地图分区的只读预览显示资料，图片和位置从地图编辑页核对。底部“保存草稿”或“发布”均先校验，再展示差异，点“确认保存”才写入云端；草稿不会替换当前公开版本。取消或归档先选择对应活动状态，再点“预览保存”。发布与来源核实是两件事。
5. “图片空间与失败上传”可查看预算；需要时明确确认“清理失败上传”，只清理到期15分钟后且没有历史/当前引用的未完成或失败资产，ready不删除。

当前已收到2048×1323的用户全场图，12:30入场已确认；闭馆、箭头可走含义与C17目录/图名称冲突仍需核实。地图来源授权记录、真实入口和至少一段可信通道准备独立于软件完成。详见 [地图指南](MAP_GUIDE.md)、[路线限制](ROUTING.md) 与 [部署决策](DEPLOYMENT_DECISION.md)。

## 已上线的旧公共模板兼容入口

选择“新建模板”或已有模板，打开“导入活动文件”，上传或粘贴活动包，点“预览”。核对来源、日期与场次后，点“保存并发布”供队长使用，已发布模板点“保存并下架”；新建或未发布模板点“保存为未发布”。每次保存都生成新版本，并立即切换该模板的最新公开状态，没有另行发布草稿的步骤。历史版本保留，但旧已发布版本不会在最新版本下架后重新出现。已有小队安排不变。发布决定该版本进入公共列表；下架不会删除现有小队快照。更新必须带 expectedRevision 并生成新版本，不能就地改变所有队的安排。维护者用 [JSON 格式](EVENT_JSON_FORMAT.md)，不得在活动包写成员/管理权限。

REDLAND 模板是 2026-10-02 至 10-06 空场次框架，09:00–21:00 待确认；真实资料要确认后再发布，不能宣传例子为官方资料。后台仅应展示必要小队元数据用于停用，不展示全员私密备注。滥用处理可关闭/归档小队，保留脱敏必要记录，避免输出凭据。

日常查配额、备份、故障与回滚见 [运维](OPERATIONS.md)。发布前核验根凭据和创建码未进入 dist、Git 和日志，退出后会话失效。当前真实后台界面/远程操作是否通过以 [发布检查](RELEASE_CHECKLIST.md) 为准。

## 活动建队码（新版隔离预发布）

打开已发布公开活动的编辑页，选择“建队码”，点“生成建队码”。默认有效24小时，绑定当前活动且只可建一队。成功后点“复制长文字码”交给队长；完整码仅本次生成显示，关闭后历史不提供明文恢复。列表显示可用、已使用、已撤销或已过期及实际到期时间。

只对可用码显示“撤销该码”；点开后确认或取消。确认撤销成功后不能再建新队，既有小队不因撤销其他码删除。管理员密码、建队码、队长恢复和成员邀请是不同权限，不能互相代替。响应丢失保留同一操作重试，不重复签发；复制失败有明确提示。
