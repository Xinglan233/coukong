# 路线与时间

本轮路线功能实施中，尚未完成生产验收。GPS、多楼层自动路线、自由站点优化和实时共享位置未实现，不显示为可用能力。

## 顺序不是导航

收藏表示想去，不占时间；加入安排须本人确认日期和分钟，才影响日程；加入路线只表示经过顺序，不自动变预约。取消收藏、删除路线都不能自动删除已有日程。“去过”是手动标记，不是官方签到。

首发路线用手动起点与明确的站点顺序，不依赖定位权限。手机应可上移/下移站点。固定场次的时间不能被路线计算器调整。没有已确认通道时保留地点清单，明确哪些路段不能生成，不画穿摊位的直线假装导航。

当前合同限制每活动最多 1000 个地点、2000 个通道节点、4000 条边，每日路线最多 100 站。这是有界输入约定，不是已验证万人并发或最大规模性能。

## 人工路网

管理员依据真实资料建立节点和连线，明确双向/单向、可用/关闭、日期及确认状态，地点必须显式关联路网节点。图上交叉不代表连通，共享节点才是路口；不能按几何最近点自动穿墙。未确认和关闭边不进入可走路径。

路网与地图版本匹配，换图、移点或封路后已有路线过期并须重算。局部覆盖可以使用，但应说明范围和缺路段。不连通时返回缺段，禁止偷偷连直线跨地图/楼层。无障碍条件未知时不能承诺无障碍路线。

## 单位与估计

最短路使用统一权重单位。已知通行秒数可作时间权重；只有图像几何权重时只能描述相对顺路，像素不等于米。没有比例尺、实测距离或人工通行时间，不显示精确米数和 ETA。部分路段时间未知则整体无法完整估计，未知不是零。步行速度与排队时间须注明假设，不是实时现场数据。

个人安排保持一分钟精度，路线内部可以用秒。两固定场次之间的移动预留取 `max(路线通行时间, 上一场后缓冲 + 下一场前缓冲)`，不重复叠加同一移动需求；额外游逛再加本人确认的停留与排队。已扣缓冲的共同空闲窗口不能重复扣同一缓冲。位置或时间未知显示“无法判断”，不推断赶得上。

共同空闲不保证大家能到同一集合点。集合提议需要队员明确回应，不自动改成忙碌或显示全队已确认；完整提议流程未交付时，只可明确共享地点链接作为降级。

路线是建议，不保证临时封路、排队和现场安全。正式使用前核实真实入口和至少一段可信通道；当前 REDLAND 已收到用户全场图，但彩色箭头的可走含义与可信通道仍待核，不宣称现场导航完成。见 [地图指南](MAP_GUIDE.md)。

## 停留、排队与个人时间窗口（开发分支）

在“计划”→“路线”中，每站点“停留与排队”，填写0–1440整数分钟；填0表示明确无需额外时间，留空表示未知。时间为本人估计，不是库存、实时排队或官方预约信息。

填写“本日在场时间”和个人安排后，系统用已经扣过本人缓冲的个人可用窗口检查剩余路线，另加确认的停留与排队，不重复扣缓冲。通道时间未知、起点未选、地点失效或地图待复核时不判断赶得上。已走站点不再计入剩余路线。

只有窗口确实放得下才出现“加入个人安排 起止时间”。主动点击后建立一条个人忙碌安排，另点“保存个人计划”才上传；收藏与路线不随此操作改动。新增安排结束边界向上补足一分钟，原13:07–13:52和固定场次不改、不按显示网格取整。
