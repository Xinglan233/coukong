# 地图与标点

活动支持地图上传、显示、标点与人工路网编辑。REDLAND已发布全场图，地点和通道尚未定位，不提供猜测导航。实际验证范围见 [发布记录](RELEASE_CHECKLIST.md)。

## 先准备有权使用的图

地图必须有来源和使用授权记录，管理员发布不等于来源已核实。用户提供的 REDLAND 全场地图已真实物化并查看像素，尺寸 2048×1323；12:30 入场由用户确认。旧 A02 局部来源图不替代这张全场图。闭馆时间、彩色箭头是否代表可走通道仍待核实；C17 目录与图上名称不一致，不自动合并。地图来源与使用授权应随发布记录保留；第三方候选场次表有 998 项、缺 2 项且非完整官方资料。

上传只接受实际 PNG、JPEG、WebP，不接受 SVG、HTML、脚本、PDF 或动图。当前共享合同设置每张源图最多 12 MiB、2400 万像素、每活动最多 5 张；这是输入上限，尚不表示最大图像已经通过真实媒体存储和免费运行时验收。图片去除非必要 EXIF；图中文字应仍可读，不能无声过度压缩。

地图文件单独存持久媒体，活动 JSON 只绑定 assetKey、哈希、尺寸和版本。浏览器 Blob URL、函数临时磁盘、大图 base64 和 D1 JSON 都不能代替真实媒体存储。媒体使用私有Vercel Blob与Node入口，生产JPEG已实际上传、净化和读取；没有开通 R2，不以免费额度名义开启可能自动计费资源。

## 虚构练习资料

[漫展示例 JSON](../examples/convention-demo.v2.json) 配套 [2000×1000 自绘 PNG](../examples/assets/convention-demo.png)，包含 U 形测试通道，仅用于格式与算法练习，不是 REDLAND 地图或真实导航资料。[通用活动 v2](../examples/event-generic.v2.json) 不带地图。文件大小、SHA-256、图像尺寸及下载一致性纳入 docs:check；JSON 只含资产清单，地图文件另行绑定，不能说 JSON 已包含原图。

## 坐标与校对

原点是实际图片左上角，x 向右、y 向下，坐标在 0–1 之间，关联地图 ID 与版本。2000×1000 图片的 (0.25,0.6) 对应像素 (500,600)。容器留白不计入坐标，标点、通道、路线共用同一缩放平移变换。

标点应关联稳定地点 ID，不以名称或摊位编号认领。未知位置保持未知，不补 (0,0)。先标入口和实际需要的位置，再核对列表里尚未定位的地点；缩放时不能误标点。地图与列表是同一份地点资料，地图加载失败时列表与日程仍可用。

裁剪、旋转、改布局或换底图后，点位和路线需要重新校对。仅构图完全不变的等比例重采样才可经预览确认复用。保留旧地图版本与引用直到迁移/回滚完成，不覆盖同一路径假定缓存已更新。深色模式不反色处理底图图例。

## 离线与备份

只有已成功下载的活动地图和匹配版本数据才能离线看；首次打开不能称完全离线。准备时确认地图、地点、通道、个人计划的版本与最后更新时间，失败保留可识别的旧快照并提示过期。个人快照与公开地图缓存分开。

数据库备份不包含图片原文件。恢复必须同时验证媒体、哈希、版本与引用，并在隔离环境真正打开地图；缺资产显示缺失，不能把恢复 SQL 成功当作地图恢复通过。详见 [部署决策](DEPLOYMENT_DECISION.md) 和 [路线限制](ROUTING.md)。

## 图片版本与空间

源图实际类型、12MiB、2400万像素与动画检查在 Node 侧执行。净化源图自动纠正 EXIF 朝向并去除 EXIF/XMP/ICC，重新记录尺寸和哈希；显示图长边最多2048、最大3MiB，优先无损 WebP，超限才用质量90且仍超限拒绝。净化源图保留为不可变版本，临时上传图只在激活成功后尝试清除。上传完成仍须预览并保存活动引用，失败不能破坏旧地图。

后台“图片空间与失败上传”中的“查看图片空间”显示应用预算；“清理失败上传”需明确不可恢复确认，只处理过期15分钟以上、无任何历史/当前引用的失败或未完成上传。所有 ready 及被历史版本引用的资产受保护。每次最多5候选、每资产20对象，存储确认清空后才标记 revoked 并释放预算。不得将清理当成删除旧正式地图。详见 [运维](OPERATIONS.md)。
