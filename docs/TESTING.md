# 测试与证据

运行 `npm run verify` 聚合类型、lint、单元、真实本地 D1/API 集成、文档与构建；`npm run test:e2e` 单独执行浏览器发布门禁。`npm run docs:check` 校验文档链接、Schema/业务例子、九个错误夹具、下载文件和命令环境变量一致性。测试环境须与生产隔离。

## 必测断言

- 分钟往返 `13:07–13:52`、选择步长不改数据、第 5.4 精确三段交集、半开边界、跨午夜缓冲、24:00、设备时区不漂移与 DST 过渡日拒绝。
- 未确认不算全天空、明确不能参加有效、子集不忽略未确认、时间变更保留旧回复并要求复核。
- 三个独立身份创建/加入/提交/回读；同名、跨队、私人回复、移除撤销、双 revision 并发、幂等响应丢失、同操作不同正文拒绝、CAS 零行从属写入无副作用。
- 三个例子通过 Schema 与业务，九个夹具按阶段拒绝；未知字段、大小/数量、并行场次、原子导入、版本冲突、导出回导和下载一致。
- 旧数据成功/失败原文均保留，旧朋友不冒名，旧分享过大/超时拒绝，hydration 不覆盖数据。
- 断网/超时/HTML 错页/配额失败保留草稿；隐藏页面停轮询；深链接、恢复权限、PWA 更新、离线和冷启动。
