# 队长指南

直接小队按钮路径已上线；活动内“同行”属于新版隔离预发布范围。版本与待验项见 [发布检查表](RELEASE_CHECKLIST.md)。

首页“创建小队”后，简单约饭只需标题、日期和每天候选时段。可从公共模板复制活动资料，复制后本队保存自己的快照；公共模板更新不会自动改变本队。

创建使用管理员提供的站点创建码。成功后在“成员”→“管理小队”分开保存管理入口和邀请入口；邀请与二维码可发群，管理入口只自己保存。自己要参与也以成员身份加入。队长不能读成员私密备注或替他们提交。

## 导入与维护活动资料

底部“成员”→“管理小队”打开管理面板。“导入活动文件”支持上传 `.json` 和粘贴文本，点“预览”，核对后点“确认导入”；[格式说明](EVENT_JSON_FORMAT.md) 和三个 [示例目录](../examples) 可直接下载。导入活动不是导入个人回复。每次更新整包替换，稳定场次 ID 保持不变；一个非法字段导致整个包不写入。

更新前核对新增、修改、删除场次和时间影响。日期、开放区间、场次时间/删除及计算默认值改变时，旧回复保留但标为“需要重新确认”，旧场次快照不会默默改变。已有确认回复后不能直接改时区，请新建小队。无变化重导入不重复建场次。版本冲突请重新预览，不要覆盖别人刚保存的资料。

## 管理成员与结束活动

在底部“成员”查看加入和确认人数，加入人数不包括未打开邀请的人。同名是独立成员，移除时核对稳定身份。更换邀请链接后旧邀请不能新加入，既有成员权限保留；移除成员会撤销其在线权限，但不能远程抹除已下载副本。

在“管理小队”点“关闭填写”停止加入/回复，“归档”表示收尾，“删除小队”会移除云端小队及对应凭据；删除前导出活动和必要数据并完成二次确认。清除本机记录不会删除云端。真实操作入口及 API 对应见 [API](API.md)，仍待验项目见 [发布检查](RELEASE_CHECKLIST.md)。

## 新活动内同行（尚未生产发布）

公开活动内打开“同行”，点“创建小队”，填写小队标题和创建码。此小队保存公共活动快照，队长不能改公共地图或场次；已有个人计划不自动分享。自己以队员身份加入后，点“同步本人计划到此小队”，核对后“提交”；收藏、路线不会分享给其他队员。参与多个小队时分别检查并提交，不认为保存个人计划已经提交全部小队。

公共活动更新在“成员”→“管理小队”点“核对并更新活动资料”；私人日常小队才使用“导入活动文件”。完整集合提议未实现，不显示全员已确认。实际功能缺项与待验范围见[活动升级P0状态](ACTIVITY_P0_STATUS.md)。
