# 维护计划

## 已发布基线

活动优先、个人计划、地图媒体、路线编辑和多人分钟协调已进入main。当前功能/API为 `bba05f27c87ea676a1b8a870185d7e64f4f7e4e0`。公开文档与前端纯文档提交分别记录，不改变API版本。

## 维护约束

- 增量维护当前项目，保护未提交工作，不强推main。
- 保持用户确认的Figma界面、公共组件、四入口及现有URL；不以文档或视觉工作改业务。
- 时间精确到1分钟，快捷步长独立；收藏、安排、路线和逐队提交独立。
- 保持作用域权限、CAS、幂等、预算和离线草稿保护。
- 生产与测试隔离，只使用免费资源；不自动购买、升级或扩大权限。
- 真实资料按来源核对，不造REDLAND坐标、通道、闭馆或缺失时段，不添加库存/预约功能。

## 下一步验证

1. 维护者按受控流程完成当前生产净化源图与显示图备份。
2. 在命名测试小队完成当前生产三独立身份完整链路。
3. 用真实手机和中国大陆网络检查现场使用、微信及离线恢复。
4. 核对REDLAND缺失时段、地图重号异名、真实坐标与可走通道，再发布对应资料版本。
5. 在实际平台测量最大复杂图片及WorkerCPU、内存与额度。
