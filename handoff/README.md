# 同野·游交接附件

从 [交接总览](../docs/HANDOFF.md) 开始。此目录是需求和参考资料附件，不含登录凭据、数据库备份、签名链接或私密测试日志。

阅读顺序：

1. [最新决定](requirements/latest-decisions.md)：冲突覆盖和当前开发/发布边界。
2. [原始执行包入口](requirements/original-execution-package/START_HERE.md) 与 [完整原要求](requirements/original-execution-package/PROMPT.md)。
3. [完整700行活动升级](requirements/activity-and-visual/activity-update.md)。
4. [完整视觉专项](requirements/activity-and-visual/visual-style-update.md)。
5. `references/`三张真实原版图和来源记录；视觉复用，不恢复旧业务。
6. [原始需求索引](SOURCE_INDEX.md) 和 `manifest.sha256.json`，核对附件齐全与字节哈希。

所有原始文件按已获授权的本机来源复制；不以摘要替代原文。两份旧Markdown来自授权文本传递后的保存版本，与原zip清单哈希不同，见 `source-manifest-check.json`。其余原包文件匹配，不修改文件伪造原zip校验通过。
